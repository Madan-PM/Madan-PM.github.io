# 🌐 Madan P M – Portfolio Website

## 🚀 Overview

This is a **personal portfolio website** built to showcase my professional experience, skills, and customer impact in the **BPO and health insurance operations domain**.

The site highlights my expertise in:

* Claims processing
* Customer experience
* Operations management
* Team leadership

It is designed with a **modern Apple-style UI**, responsive layout, and interactive elements to provide a clean and professional user experience.

---

## ✨ Features

### 🧑‍💼 Professional Introduction

* Clear personal branding
* Structured summary of experience and strengths

### 🛠 Skills Section

* Covers key competencies like:

  * Claims Processing
  * Customer Experience (CX)
  * SLA & TAT Management
  * Escalation Handling
  * Tools (Freshdesk, CRM, Excel)

### 📊 Experience Section (Interactive)

* Includes all roles across companies
* **Click on any role → opens detailed modal**
* Displays full bullet points from resume

### 💬 Customer Testimonials

* Real customer reviews from:

  * Google Reviews
  * LinkedIn
* **Image preview on click (modal view)**

### 📞 Contact Section (Clickable)

* Email → opens mail client
* Phone → opens dialer
* LinkedIn → opens profile in new tab

### 🌗 Light / Dark Mode Toggle

* Smooth animated switch
* User-friendly icons (🌙 / ☀️)
* Enhances accessibility and UI experience

### 📱 Responsive Design

* Works across:

  * Desktop
  * Tablet
  * Mobile

---
